# โมเดลธุรกิจแชร์ทรัพยากร + คืนค่าเป็นส่วนลด (Token Economy)

**ฉบับคำนวณ · 2026-10-22** · โมเดล: `pasadhi/commercial/token_model.py` · ตัวเลข: `commercial/results/token_model.json`

> ตัวเลขฮาร์ดแวร์มาจากการวัดจริง (i7-8550U 74 GFLOP/s ต่อเครื่อง, ต้นทุน ฿551/เครื่อง/เดือน)

## 1. แบ่งชั้นการให้บริการ (Layer split)

| Layer | สัดส่วน | ใคร | จ่ายอะไร | ได้อะไร |
|---|---:|---|---|---|
| **Free** | **10 %** (145 เครื่อง) | โรงเรียน, NGO, open source | ไม่จ่ายเงิน | ใช้ compute ฟรี + **สะสม credit** จากการเอาเครื่องมาช่วย |
| **Standard** | **40 %** (580 เครื่อง) | SME, สำนักงาน | **฿1,490/เครื่อง/เดือน** (รายปี ฿15,900) | ใช้ได้เต็มที่ + credit ลดบิลได้ถึง 50 % |
| **Premium** | **50 %** (725 เครื่อง) | องค์กร, โรงงาน, ภาครัฐ | **฿3,490/เครื่อง/เดือน** (2.3×) | SLA 99.5 %, isolation, 24×7, priority queue + credit |
| Liquidity | 10 % ของกำไร | ผู้ถือ PSD | — | reserve หนุน 1 PSD = ฿1 |

**ทำไม 10/40/50:** 10 % เป็น Marketing/CSR ที่วัดผลได้ (ไม่ใช่ของแถม), 40 % คือฐานรายได้ที่คาดเดาได้,
50 % คือกำไรจริงเพราะจ่ายแพงกว่าแต่ต้นทุนต่อเครื่องเท่าเดิม → margin ต่อเครื่องสูงกว่า

## 2. Compute Credit (CC) — "เอาเครื่องมาช่วย ได้ส่วนลด"

```
1 ชั่วโมงเครื่องที่ส่งงานจริง = 2.5 CC (1 CC = ฿1 ของส่วนลด)
เพดานใช้ลด = 50 % ของใบแจ้งหนี้เดือนนั้น
หมดอายุ 12 เดือน · ไม่แลกเป็นเงินสด · โอนให้คนอื่นไม่ได้
นับเฉพาะงานที่ส่งมอบสำเร็จ (ไม่นับ heartbeat หรือเครื่อง idle)
```

**ตัวอย่าง:** ลูกค้า Standard 10 เครื่อง ปล่อยเครื่องว่าง 4 ชม./วัน = 1,200 ชม./เดือน
→ ได้ 3,000 CC = ฿3,000 แต่บิล ฿14,900 → ใช้ได้จริง ฿3,000 (20 % ของบิล) ไม่ใช่ 50 % เพราะเพดานไม่ผูก

## 3. Liquidity Token (PSD) — 10 % ของกำไร

- ทุกเดือนนำ **10 % ของกำไร** เข้า reserve
- ออก PSD 1:1 กับ reserve (1 PSD = ฿1 มูลค่าตามบัญชี) — ใช้เป็นส่วนลดค่าบริการรอบถัดไป
- **ไม่ซื้อขาย ไม่โอน ไม่เก็งกำไร** — ถ้าจะทำให้ซื้อขายได้ ต้องขอใบอนุญาตสินทรัพย์ดิจิทัล (พ.ร.ก.สินทรัพย์ดิจิทัล)
  **คำเตือน:** การให้ผลตอบแทนผูกกับกำไรอาจเข้าข่ายหลักทรัพย์/สินทรัพย์ดิจิทัล ควรปรึกษาที่ปรึกษากฎหมายก่อนเปิดขายให้บุคคลทั่วไป

**Stress case:** ถ้าทุกเครื่องช่วยเต็มที่ 720 ชม./เดือน → CC = ฿2.35M เกินเพดาน 50 % (฿1.70M)
→ ระบบตัดที่เพดาน กำไรเหลือ **฿738,275 (43.5 %)** — **ยังไม่ขาดทุน** เพราะเพดาน 50 % คือเบรกมือ

**ข้อสรุปสำคัญ:** กลไกนี้ *ไม่ใช่* การแจกฟรี แต่คือ **ส่วนลดที่ซื้อ loyalty** — ต้นทุนจริงของการให้ 1 CC
คือ ~฿0.19 (ค่าไฟต่อชั่วโมง) ไม่ใช่ ฿1 เพราะเครื่องเปิดอยู่แล้ว (ดู §6)

## 6. "ค่าเปิดเครื่องแทบเป็นศูนย์" — คำนวณให้เห็น

| สิ่งที่เกิดขึ้น | ต้นทุน |
|---|---:|
| Boot + agent + model load 45 วินาที (ต่างจาก idle 12 W → 45 W) | **฿0.0017** |
| หนึ่งชั่วโมงของราคา Standard (฿1,490 ÷ 720) | ฿2.07 |
| Boot คิดเป็นสัดส่วนของงาน 1 ชั่วโมง | **0.08 %** |
| Boot คิดเป็นสัดส่วนของงาน 10 นาที | 0.5 % |
| Boot คิดเป็นสัดส่วนของงาน 1 นาที | 5 % |

และเพราะเครื่องลูกค้า **เปิดอยู่แล้วในเวลาทำงาน** (8 ชม./วัน, ว่าง ~60 %) → 容量 ที่ได้มาฟรีคือ
**~4.8 ชม./เครื่อง/วัน = 144 ชม./เดือน** ต้นทุนเพิ่มคือค่าไฟส่วนต่างเท่านั้น (~฿0.19/ชม.)
นี่คือเหตุผลที่ราคาขายเป็นส่วนลดได้โดยไม่เจ๊ง: **เราขายเวลาที่มีอยู่แล้ว ไม่ได้ซื้อใหม่**

## 7. กติกากันการปั่น (ต้องมีก่อนเปิดขาย)

1. CC จาก **งานที่ส่งมอบสำเร็จ** เท่านั้น มีหลักฐาน tile id + checksum
2. เพดาน 50 % ของใบแจ้งหนี้ + หมดอายุ 12 เดือน + ไม่แลกเงินสด
3. Intercompany/affiliate contribution ถูกหักสิทธิ์ (กันการปั่น credit ภายในกลุ่ม)
4. Reserve 10 % แยกบัญชี ตรวจสอบได้ (audit) และ **ไม่นำไปใช้เป็นเงินทุนหมุนเวียน**
5. ถ้าจะเปิด PSD ให้ซื้อขาย → หยุดก่อน ปรึกษากฎหมาย/ก.ล.ต.

## 8. สิ่งที่ต้องวัดก่อนเชื่อโมเดลนี้

- อัตราการยอมให้เครื่องถูกใช้ (จริง ๆ ลูกค้ายอมให้ใช้ตอนกลางคืนหรือไม่)
- CC ที่ลูกค้าแลกจริง vs ที่ออก (breakage) — ถ้าแลกต่ำกว่า 60 % กำไรจะสูงกว่าที่โมเดลนี้บอก
- ราคาที่ตลาดรับได้ที่ ฿1,490/เดือน (ทดสอบกับ 10 ลูกค้าแรก)
- ต้นทุน support จริงต่อเครื่อง (ตอนนี้สมมติ ฿80/เดือน)
