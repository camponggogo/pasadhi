# PASADHI — แผนเชิงพาณิชย์ (ฉบับลงมือขาย)

**สถานะ: M0** · ตัวเลขฮาร์ดแวร์ทั้งหมดวัดจากเครื่องจริง (i7-8550U, f32 BLAS 74 GFLOP/s)
· ตัวเลขคลาวด์เป็นราคา list โดยประมาณ ตุลาคม 2026 · FX 36 บาท/USD

---

## 1. บทสรุปผู้บริหาร

PASADHI ขาย **"เครื่องคำนวณส่วนตัวขององค์กร"** ไม่ใช่ขาย FLOPs ถูกกว่า GPU
เพราะการวัดบอกชัดว่าเราแพ้ GPU ประมาณ 17 เท่าในราคาต่อ TFLOP แต่ **ชนะคลาวด์ CPU 1.8 เท่า**
และชนะทุกกรณีเมื่อข้อมูล **ห้ามออกจากองค์กร** หรือเมื่อเครื่องมีอยู่แล้วและต้นทุนจมไปแล้ว

> ประโยคขายเดียว: **"เครื่องที่คุณมีอยู่แล้ว คำนวณงานจริงได้ วันนี้ ไม่ต้องรออนุมัติ GPU และข้อมูลไม่ออกจากตึก"**

## 2. ความจริงที่ต้องพูดให้ตรง (ใช้เป็นฐานราคา)

| ทางเลือก | บาท / TFLOP ที่ส่งมอบ | หมายเหตุ |
|---|---:|---|
| PASADHI node (duty 60 %) | **0.016** | ต้นทุนจริง ฿551/เดือน/เครื่อง |
| Cloud CPU (4 vCPU) | 0.028 | แพงกว่า 1.8× |
| Cloud GPU (1× A100) | 0.001 | ถูกกว่า 17× |

**แปลว่า:** ห้ามขายด้วยคำว่า "ถูกกว่าคลาวด์" แบบลอย ๆ ให้ขายด้วยสามเหตุผลที่วัดได้:

1. **Residency** — ข้อมูลไม่ออกจากองค์กร (PDPA, ข้อมูลลูกค้า, เวชระเบียน, เอกสารคดี)
2. **ต้นทุนจม** — เครื่องมีอยู่แล้ว ต้นทุนเพิ่มจริงคือค่าไฟ ฿138/เดือน/เครื่อง
3. **งานเล็ก–bursty** — งานที่รอ GPU queue ไม่คุ้ม หรือเช่า GPU ขั้นต่ำ 1 ชั่วโมงไม่พอดีกับงาน 40 วินาที

## 3. ลูกค้าเป้าหมาย (เรียงตามความง่ายในการปิด)

| # | กลุ่ม | Trigger ที่ทำให้ซื้อ | งบต่อปี |
|---|---|---|---|
| 1 | **สำนักงานกฎหมาย / ที่ปรึกษา** | เอกสารลูกค้าห้ามออก, ต้องการค้นและสรุปในองค์กร | ฿80k–250k |
| 2 | **คลินิก / โรงพยาบาลเล็ก** | ภาพ X-ray/ Ultrasound ต้องประมวลผลในพื้นที่ | ฿120k–400k |
| 3 | **มหาวิทยาลัย / โรงเรียนเทคนิค** | สอน distributed computing แต่ไม่มี GPU lab | ฿60k–180k |
| 4 | **โรงงาน / QC** | กล้องเก่า + เครื่องเก่า ต้องการตรวจภาพทีละมาก ๆ | ฿150k–500k |
| 5 | **หน่วยงานราชการ / รัฐวิสาหกิจ** | ระเบียบห้ามใช้คลาวด์ต่างประเทศ | ฿300k–1M |

**ยังไม่ควรไล่:** startup AI ที่ต้องการ throughput สูง (เขาไป GPU ถูกกว่า) และองค์กรที่ยังไม่มีเครื่องเลย (ต้องขายพร้อมเครื่อง = margin ต่ำ)

## 4. แพ็กเกจและราคา

| แพ็กเกจ | ราคา | ให้อะไร | Margin |
|---|---:|---|---:|
| **Core** | ฟรี (MIT) | 1 เครื่อง, CLI, kernel | — |
| **Fleet** | **฿1,490 / เครื่อง / เดือน** (รายปี ฿15,900, ขั้นต่ำ 5 เครื่อง) | scheduler, dashboard, quota, update, audit | ~63 % |
| **Appliance** | **฿45,000 / ชุด 4 เครื่อง** | เครื่อง refurb + ติดตั้ง + Fleet 1 ปี | ~30 % |
| **Pilot (4 สัปดาห์)** | **฿49,000** (สูงสุด 8 เครื่อง) | ติดตั้ง, วัด baseline, รายงานผล, เครดิต 100 % เป็นปีแรก | ~60 % |
| **Support 8×5** | +20 % ของค่า license | 4 ชม. ตอบ, อัปเดต, อะไหล่สำรอง | ~70 % |
| **Support 24×7 on-site** | +35 % | 1 ชม. ตอบ, เข้าsite 4 ชม. | ~55 % |
| **Enterprise (100 เครื่อง)** | **฿450,000 / ปี** | SSO, audit export, ที่ปรึกษา, SLA | ~80 % |

**ทำไม ฿1,490/เดือน:** ต้นทุนจริง ฿551/เดือน (ค่าเสื่อม ฿333 + ไฟ ฿138 + support ฿80) → margin 63 %
และยังต่ำกว่าค่าเช่า GPU ขั้นต่ำหนึ่งเดือน (~฿1,500–2,500) ทั้งที่ใช้งานได้ทั้งเดือน
คือ margin 70 % ตามเป้า และยังถูกกว่าค่าเช่า GPU ขั้นต่ำหนึ่งเดือนสำหรับงานเล็ก

## 6. โมเดลรายได้ 3 ปี (สมมติฐานชัดเจน)

| ปี | Pilots | Conversion | ลูกค้าใหม่ | เครื่องเฉลี่ย/ลูกค้า | ARR |
|---|---:|---:|---:|---:|---:|
| 1 | 12 | 40 % | 5 | 20 | ฿1.9M |
| 2 | 24 | 45 % | 11 | 30 | ฿8.2M |
| 3 | 36 | 50 % | 18 | 40 | ฿21.9M |

สมมติฐาน: ACV ≈ ฿190k (10 เครื่อง × ฿1,490 × 12 + support 20 %) · ไม่รวม Appliance (margin ต่ำ) · churn 5 %/ปี
**ตัวเลขนี้เป็นเป้า ไม่ใช่พยากรณ์** — ต้องตรวจกับ pipeline จริงทุกไตรมาส

## 8. ความเสี่ยงและแผนรับ

| ความเสี่ยง | ผลกระทบ | แผนรับ |
|---|---|---|
| ลูกค้าถามว่า "GPU ถูกกว่า" | สูญเสียดีล | ยอมรับตรง ๆ แล้วชี้ 3 เหตุผลใน §2 + คำนวณ TCO ให้เห็นรวมค่า egress/ops |

| Support กิน margin | กำไรหาย | บังคับ Fleet + support 20 % ตั้งแต่ปีแรก, จำกัด on-site ตามสัญญา |

| MIT license ถูก fork ไปขาย | รายได้หาย | ขาย support + enterprise feature (SSO, audit, HA) ที่ไม่อยู่ใน Core |
